## COMP20280

This project focuses on implementing and analyzing a randomized binary search tree known as a Treap. The Treap was built as a fully generic Java class, maintaining both binary search tree and heap properties through the use of random priorities. Its functionality was tested with a complete suite of unit tests and compared in performance to a custom AVLTreeMap implementation and Java’s built-in TreeMap. Performance benchmarks covered core operations such as insertion (single and batch), search (successful and unsuccessful), deletion, and in-order traversal, using different input sizes and patterns. The results were collected over 30 trials per case and saved to CSV for analysis.

In addition to the Treap data structure, the project also included sorting benchmarks. The Treap was used to implement TreapSort, and its performance was compared against PQSort (using Java’s PriorityQueue), Java’s built-in TimSort (via Arrays.sort), and custom QuickSort and MergeSort implementations. All algorithms were tested on random, nearly sorted, and reverse sorted inputs across a range of sizes. Both execution time and memory usage were recorded. All code was committed to GitHub, and the project deliverables include a short report with charts and performance discussion, along with a poster for presentation.
